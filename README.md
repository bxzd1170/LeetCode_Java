# LeetCode_Java Hot100 刷题仓库
Java后端考研/面试刷题仓库，专注LeetCode Hot100高频算法题，全部使用Java实现。

## 📦 仓库内容
- src：Java完整题解代码（可直接运行）
- 题号_题目名.md：每道题详细解题思路、暴力/优化双解法、复杂度分析
- medium / hard：按难度分类归档题解文档
- daily-log.md：每日刷题打卡、错题复盘记录

## 📁 目录规范
1. 代码统一放在 src 包下，按题型分包（数组、链表、二叉树、DP等）
2. 文档命名规则：`题号_题目全称.md`，方便搜索定位
3. 难度文件夹 medium/hard 存放对应难度思路文档

## 💡 刷题笔记规范
每篇md固定包含4部分：
1. 题目链接 & 题干简述
2. 暴力解法思路 + 代码
3. 最优解法思路 + 注释代码
4. 时间/空间复杂度、易错点复盘
